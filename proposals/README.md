# Historical extension proposals

The JSON files in this directory are immutable design inputs from the initial `research-ideation@2` implementation. They intentionally retain their original catalog digests and component versions, so `extension-check` should reject them as stale against the current catalog.

The active implementation is `research-ideation@3` in `workflows/research-ideation.v3.json`; its exact production schemas and component descriptors live in `packages/research-ideation`. Create a new proposal with the current catalog digest for any further extension instead of editing these historical records.
